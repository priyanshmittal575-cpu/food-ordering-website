# Food Ordering Website

Restaurant menu and online food ordering interface with category filtering, dynamic cart calculations, and order summary.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/food-ordering-website.git
   cd food-ordering-website
   ```
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox).
